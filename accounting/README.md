# 📊 公司帳務管理系統

符合會計原則的複式記帳（借貸平衡）網頁應用，可直接部署至 GitHub Pages，資料自動同步至 GitHub Gist。

## 功能一覽

| 模組 | 功能說明 |
|------|---------|
| 🏠 儀表板 | 本月收支結餘卡片、支出圓餅圖、月份趨勢圖 |
| ⚡ 快速記帳 | 選收入/支出自動產生複式分錄，含稅三行自動計算 |
| 📋 傳票記帳 | 多行分錄、借貸平衡驗證才可儲存 |
| 🧾 電子發票 | 自動產生發票號碼/隨機碼、5% 營業稅分錄、發票清冊匯出 |
| 📖 分類帳 | 依科目查詢明細與逐筆餘額 |
| ⚖️ 試算表 | 全科目借貸餘額加總，帳務平衡驗證 |
| 📈 損益表 | 按月份查看收入、費用、淨利 |
| 🏛️ 資產負債表 | 累計至月底，資產 = 負債 + 權益自動勾稽 |
| 🗂️ 會計科目 | 五大類內建科目，可自訂新增 |

## 會計科目（五大類）

- **資產**（Asset）：現金、銀行存款、應收帳款、固定資產等
- **負債**（Liability）：應付帳款、應付薪資、應付營業稅等
- **權益**（Equity）：股本、保留盈餘、本期損益
- **收入**（Income）：銷貨收入、服務收入、利息收入等
- **費用**（Expense）：薪資、租金、水電、交通、廣告等

## GitHub Pages 部署步驟

1. 在 GitHub 建立新 Repository（例如：`my-accounting`）
2. 將 `index.html` 上傳至 Repository 根目錄
3. 前往 **Settings → Pages → Source**，選擇 `main` 分支
4. 等待約 1 分鐘後，訪問 `https://<你的帳號>.github.io/my-accounting/`

## GitHub Gist 資料同步

資料以 JSON 格式儲存至 **GitHub Gist**，重新打開頁面後自動載入。

### 設定方式

1. 前往 [GitHub Settings → Developer Settings → Personal Access Tokens](https://github.com/settings/tokens)
2. 建立新 Token，勾選 **`gist`** 權限
3. 點擊應用程式右上角的 🔄 **同步** 按鈕
4. 貼上 Token，Gist ID 留空（首次使用自動建立）
5. 點擊「儲存並同步」

> 之後每次點擊🔄同步按鈕，資料將自動備份至 GitHub Gist

## CSV 匯出

右上角兩個按鈕：
- **本月 CSV**：匯出本月所有傳票分錄
- **全部 CSV**：匯出所有歷史記錄

欄位：日期、傳票號、摘要、科目代號、科目名稱、類型、借方、貸方、發票號碼

## 電子發票

記錄收入時勾選「開立電子發票」：
- 自動加計 5% 營業稅
- 產生隨機發票號碼（AB 開頭 8 碼）與 4 位隨機碼
- 產生「應付營業稅」貸方分錄
- 於「電子發票」頁面查詢及匯出發票清冊

## 複式記帳原理

每筆交易均符合：**借方合計 = 貸方合計**

| 交易類型 | 借方 | 貸方 |
|---------|------|------|
| 收入（無發票）| 銀行存款 | 銷貨收入 |
| 收入（含發票）| 銀行存款（含稅） | 銷貨收入 + 應付營業稅 |
| 支出 | 費用科目 | 銀行存款 |
